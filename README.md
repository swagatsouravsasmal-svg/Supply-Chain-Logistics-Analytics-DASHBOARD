# 📊 Supply Chain & Logistics Analytics Dashboard
## 📌 Project Overview
This project is an interactive **Supply Chain and Logistics Analytics Dashboard** developed using **Microsoft Power BI**.
The dashboard provides a comprehensive view of supply chain operations, including suppliers, inventory, shipments, customers, revenue, profit, order quantity, delivery performance, and logistics delays.
The goal of this project is to transform supply chain data into meaningful business insights that can support better operational and strategic decision-making.
---
## 🎯 Project Objectives
- Analyze overall supply chain performance
- Monitor supplier performance and lead time
- Track inventory levels and inventory value
- Analyze shipment quantity and delivery status
- Identify shipment delays and delay reasons
- Analyze customer revenue
- Monitor profit and revenue trends
- Understand order quantity and purchasing patterns
- Identify areas for supply chain improvement
---
